# britter.dev

Source for [britter.dev](https://britter.dev) — _Reproducible Thoughts_, the personal
website and technical journal of Benedikt Ritter. Built with
[Astro](https://astro.build) and Tailwind CSS, deployed on Netlify.

## Development

The easiest way to get a working environment is [direnv](https://direnv.net) with
the included Nix flake (`.envrc` runs `use flake`). It provides Node and the
pre-commit hook. Alternatively, use your own Node installation.

| Command                  | Action                                           |
| :----------------------- | :----------------------------------------------- |
| `npm install`            | Install dependencies                             |
| `npm run dev`            | Start dev server at `localhost:4321`             |
| `npm run build`          | Typecheck (`astro check`) and build to `./dist/` |
| `npm run preview`        | Preview the production build locally             |
| `npx prettier . --check` | Check formatting (CI enforces this)              |

Formatting is enforced by a Prettier pre-commit hook. The hook configuration in
`.pre-commit-config.yaml` is generated by [git-hooks.nix](https://github.com/cachix/git-hooks.nix)
— to change hooks, edit `flake.nix` instead.

## Writing blog posts

Posts live in `src/content/blog/` and **must** be named `YYYY-MM-DD-slug.md`
(or `.mdx`): the publish date and the URL `/blog/YYYY/MM/DD/slug` are derived
from the filename, and the build fails if the date prefix is missing.

Frontmatter fields:

```yaml
---
title: "Post title"
description: "Short description used in listings and meta tags."
topics: ["Nix", "Gradle"] # optional
updated: 2026-11-01 # optional
---
```

Site-wide data (navigation, bio, blog branding) lives in `src/config/data.json`.
OG images are generated at build time — each post automatically gets
`/og/<id>.png`.

## Testing

Playwright tests start the dev server automatically (port 4321):

- **Functional tests**: `npx playwright test --project=functional` — checks meta
  tags, page titles, the RSS feed, and redirects. Runs without a browser.
- **Visual regression**: `./run-visual-tests.sh` — runs the tests in Docker,
  same as CI. Browsers are not installed locally; Playwright's browser
  downloads don't work on NixOS.

Visual tests run in Firefox with light color scheme. Snapshots are committed in
`tests/visual-regression.spec.ts-snapshots/` — after intentional UI changes,
regenerate them with `./run-visual-tests.sh --update-snapshots` and commit the
changed PNGs.

## Deployment

The site deploys on Netlify (`netlify.toml`). Old `benediktritter.de` URLs
redirect to `britter.dev` via `public/_redirects`; redirects for renamed paths
are defined in `astro.config.mjs`. Dependency updates are managed by
[Renovate](https://renovate.com).
